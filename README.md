# Product Line Profitability and Margin Performance Analysis

## Project Overview
This project analyzes the product-line profitability and margin performance of Nassau Candy Distributor using Python. The objective is to identify profitable products, evaluate gross margins, and generate business insights from sales data.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The dataset contains 10,194 records and 18 columns related to sales, products, customers, costs, and gross profit.

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Key Performance Indicator (KPI) calculation
5. Product and division profitability analysis
6. Gross margin analysis
7. Data visualization
8. Business insights and conclusion

## Key Performance Indicators
- Total Sales: 141,783.63
- Total Cost: 48,340.83
- Total Gross Profit: 93,442.80
- Overall Gross Margin: 65.91%
- Total Transactions: 10,194
- Unique Products: 15
- Number of Divisions: 3

## Key Findings
- Wonka Bar - Scrumdiddlyumptious generated the highest gross profit.
- Everlasting Gobstopper had the highest gross margin.

## How to Run
1. Download the repository files.
2. Install the required Python libraries.
3. Open `Nassau_Candy_Profitability_Analysis.ipynb` in Jupyter Notebook.
4. Run the notebook cells in order.
